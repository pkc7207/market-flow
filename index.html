MacroDroid의 OCR TXT를 읽어 여러 화면의 중복을 합칩니다. 매수−매도=순매매(±1억원)와 기관 세부 합계를 검산합니다. 자동 검산이 원본 숫자의 정확성을 보장하지는 않으며, 기존 통계는 검토·저장 전까지 변경되지 않습니다.

※ 주말 수집은 전 거래일 화면이 남아 있어도 저장이 차단됩니다. 평일 공휴일 여부와 OCR 숫자 오류는 별도 검토가 필요합니다.

MacroDroid가 첫 OCR 앞에 @KWF_TS={system_time};를 파일에 기록하면, 해당 회차의 거래일·시각을 한국시간(KST)으로 자동 확정합니다. 기존 표식 없는 OCR 회차는 추측하지 않고 수동 확인 방식으로 유지합니다. 숫자 11개 검산 및 원문 대조는 계속 필요합니다.

회차를 선택하면 해당 회차의 확인 상태가 표시됩니다.
